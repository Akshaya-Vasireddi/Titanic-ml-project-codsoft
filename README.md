# 🚢 Titanic Survival Prediction

A machine learning project that predicts whether a passenger survived the Titanic disaster based on features like age, gender, ticket class, and fare.

## 🤖 Models Compared

| Model | Accuracy |
|-------|----------|
| Logistic Regression | ~80% |
| Decision Tree | ~78% |
| K-Nearest Neighbors | ~79% |
| **Random Forest (Tuned)** | **82.68% ✅** |

---

## 🧠 Key Features Used
- Passenger Class, Gender, Age, Fare
- Family Size, Is Alone, Has Cabin
- Title (Mr, Mrs, Miss, Master, etc.)
